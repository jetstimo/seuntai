about=Seuntai cleans line networks (cables, routes) that were digitised more than once, so several lines run on top of or beside each other. Pick a line layer, tick the product/LOB values found in its attributes and press Run: in every corridor only the line with the oldest creation date is kept, unchanged and with all its attributes, and the result is saved as a Shapefile with an offline HTML report that explains every decision. Duplicates are found by distance, not identical geometry; cables drawn on both sides of the same road become one line by matching them to OpenStreetMap roads. A folder tool processes every line dataset in a folder; a check tool reports stacked corridors without changing the data. No extra Python packages needed; internet is used only to download the road data around your lines (a few MB per city, cached). Reports are written in Indonesian.
